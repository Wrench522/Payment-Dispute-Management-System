# Payment Dispute Management System

A web application for registering, investigating,
tracking, and resolving simulated payment disputes.

## Technology Stack
- Frontend: React and Vite
- Backend: Java and Spring Boot
- Database: PostgreSQL
- API Testing: Postman

## Core Features
- Register payment disputes
- Track dispute status
- Add investigation notes
- Record resolutions
- Maintain dispute history

This project uses simulated payment data.
